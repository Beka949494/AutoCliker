# Simple Auto Clicker (Android project)

Бұл — Android Studio арқылы APK құрастыруға арналған бастапқы жоба.

## Құрастыру
1. Android Studio орнатыңыз.
2. ZIP-ті ашып, `AutoClicker` жобасын Android Studio-да ашыңыз.
3. Gradle sync аяқталғанша күтіңіз.
4. Build > Build APK(s) таңдаңыз.

## Ескерту
Бұл үлгі Accessibility қызметін көрсететін минимал жоба. Ол дайын, толық экрандық автокликер емес; интерфейсте басу нүктесін таңдау/қайталама цикл функционалы әзірше жоқ. InDrive тапсырыстарын автоматты қабылдау не тапсырыстарды сүзу функциялары кірмейді. Қосымша Accessibility рұқсатын тек өзіңіз сенетін қолданбаларға беріңіз.
